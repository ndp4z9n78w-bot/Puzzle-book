PUZZLE STUDIO v10.7 — REMOVABLE PAGES

NEW
- Every rendered page has a Remove Page button.
- New Page Manager lists every current page with a Remove control.
- Removing a page immediately removes it from the current book.
- Remaining page numbers are recalculated automatically.
- Removed pages are excluded from direct PDF export.
- Rebuilding the book restores the generated page set.

IMPORTANT
Page removal edits the current rendered book. If you change settings and force a full re-render
or build the book again, the removed pages can return because the book is generated again.

- Offline caching
- Vector PDF exporter
- Page numbers
- KDP preflight
- Smart assembly
- Mixed puzzle books
- Exact visible version
