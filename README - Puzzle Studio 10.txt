PUZZLE STUDIO 10 — SMARTER BOOK ASSEMBLY

NEW
1. SMART SECTION BALANCING
- Sections with only 1–2 puzzles no longer waste a full standalone divider page.
- Larger section dividers are automatically aligned to right-hand pages when smart balancing is enabled.
- Existing manual right-hand section option is still available.

2. SMART SOLUTION DENSITY
"Smart by puzzle type" is now the default.
- Large/detailed solution types: 1 per page
- Medium solution types: 2 per page
- Compact solution types: up to 4 per page
Manual 1 / 2 / 4 per page settings are still available.

3. STRONGER BOOK SUMMARY
Before building, the summary now shows:
- Total puzzle count
- Difficulty distribution
- Puzzle-type distribution
- Estimated interior pages
- Trim size
- Section balancing status
- Solution density setting

4. ORGANIZED EXPORT FILENAMES
PDF and JSON project files now automatically include:
- Book title
- Puzzle type / Mixed
- Puzzle count
- Trim size
- Date

Example:
My_Book_Mixed_60Puzzles_8x10_2026-09-27.pdf

ALSO FIXED
- Removed a stale reference to the old Difficulty dropdown from project saving.
- Quick-mode summary no longer depends on the removed Difficulty control.
- KDP preflight page-count math understands smart solution density and smart section balancing.

PRESERVED
- Large-book iPhone PDF memory fix
- Build spinner/progress
- Illustrated how-to examples
- Mixed puzzle type / difficulty / quantity controls
- KDP readiness preflight
- Book presets and Book Overview
- Puzzle variety controls
